# FinStories — checklist TTS manuelle (audibilité)

Environnement: Chrome ou Edge desktop, haut-parleurs/casque actifs, compte investisseur.

1. Ouvrir `/stories`.
2. Ouvrir une histoire.
3. Cliquer **Activer la narration** (geste utilisateur obligatoire).
4. Vérifier qu'une voix française est sélectionnée (sinon installer une voix FR OS).
5. Lancer la lecture (K ou bouton play).
6. **Confirmer à l'oreille** qu'un son est émis.
7. Couper la narration (M) — le son s'arrête; les sous-titres restent visibles.
8. Recharger sans geste — la narration ne doit pas démarrer seule.

Résultat: [ ] son entendu  [ ] échec (préciser navigateur / OS / voix)
