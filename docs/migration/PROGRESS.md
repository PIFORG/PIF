## Checkpoint 2 — 2026-11-11: identity, security, sessions and administration complete

**Overall: 37 / 94 endpoints and 16 / 37 routes are migrated and verified (the whole identity domain), plus the shared financial core in Java.** All of them are below *Fully accepted*, pending cutover gates and your sign-off. The Phase 1 documents counted 38 routes; the correct number of `page.tsx` routes is 37.

### Done in this phase (implemented and tested)

**Spring mail module** (`com.pif.api.mail`).
- Preview and SMTP transports with the same configuration and production rules as NestJS.
- 18 templates, byte-identical to the NestJS output.
- A bounded asynchronous queue: delivery never changes an HTTP answer and never undoes a security action.
- Explicit outcome states: queued, captured, accepted by the relay (inbox delivery not confirmed), or failed.
- Masked recipients and no tokens in logs.
- The lockout notice is sent exactly once per lock. This closes the Phase 1 cutover blocker.

**Spring API, 26 new endpoints** (37 in total):
- registration, e-mail verification, resend, forgot and reset password;
- change password, change e-mail (request and confirm);
- sessions (list, revoke one, revoke others, logout everywhere);
- MFA (setup, enable, disable, regenerate recovery codes, status);
- deactivate and delete account, dashboard context;
- 6 admin endpoints, enforced on the server by `RolesInterceptor`, including the administrator-MFA policy and last-administrator protection.

**Angular, 13 new screens:**
- `/register`, `/verify-email`, `/resend-verification`, `/forgot-password`, `/reset-password`, `/confirm-email-change`, `/unauthorized`;
- `/settings/security`, `/settings/sessions`;
- `/admin`, `/admin/users`, `/admin/users/:id`, `/admin/audit`.

Supporting pieces:
- `adminGuard` (render decision only; the API enforces access).
- E-mail link tokens are removed from the address bar before anything is sent.
- Step-up fields, confirmation dialogs, cooldown handling, and the shared form and field components.
- No component library; styles copied from the CSS modules.

**Java financial core.**
- `apps/api/src/finance` ported to `com.pif.api.finance`, bit-identical on 3,013 golden cases generated by the TypeScript code.
- Every mismatch is classified in [FINANCIAL_PARITY.md](FINANCIAL_PARITY.md).
- No financial endpoint is exposed.
